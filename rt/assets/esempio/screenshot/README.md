# Screenshot per la lezione di esempio

Questa cartella contiene gli screenshot WebP (consigliato < 150 KB ciascuno) che `scripts/make_sample_lesson.py` incorpora automaticamente nelle corrispondenti unità della lezione di esempio.

Se un file non è presente al momento della generazione, l'unità viene creata normalmente senza immagine.

## File attesi

| File | Unità | Cosa deve mostrare |
| --- | --- | --- |
| `1.1.webp` | 1.1 Dalla registrazione al testo | Vista panoramica della pagina di una lezione già completata con il testo rielaborato. |
| `1.2.webp` | 1.2 Come leggere una lezione | Documento della lezione con l'indice delle sezioni a sinistra, il timecode cliccabile sopra un'unità e il lettore audio attivo. |
| `2.1.webp` | 2.1 Cosa caricare | Finestra «Nuova lezione» con il riquadro per caricare audio/trascrizione, i materiali facoltativi (slide, PDF, foto) e il selettore dello slot dal calendario. |
| `2.2.webp` | 2.2 Mentre RT lavora | Barra di avanzamento delle fasi durante l'elaborazione della lezione e riquadro del costo stimato prima dell'avvio. |
| `3.1.webp` | 3.1 La scheda Verifica | Pannello laterale «Verifica» aperto con un avviso, la citazione evidenziata, la correzione proposta e i pulsanti Accetta / Modifica / Ignora. |
| `3.2.webp` | 3.2 Modificare il testo | Modalità di modifica diretta del documento Markdown con pulsante Annulla e opzione per rigenerare una singola unità. |
| `4.1.webp` | 4.1 Mettimi alla prova | Pannello/pagina «Domande» con una domanda di ripasso attiva, opzioni o risposta aperta e valutazione/commento mostrati. |
| `4.2.webp` | 4.2 Stati di studio e calendario | Modalità Studio o elenco lezioni con gli stati di studio e l'anello di avanzamento, oppure la vista Calendario settimanale con le materie. |
