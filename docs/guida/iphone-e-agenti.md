# iPhone e agenti esterni

Puoi consultare le tue lezioni anche lontano dal computer e collegare RT ai tuoi strumenti di automazione e intelligenza artificiale.

## Accesso da iPhone

RT include un server web locale integrato per consultare le unità e studiare comodamente da smartphone o tablet sulla stessa rete Wi-Fi:
1. Apri **Impostazioni → Accesso da iPhone**.
2. Attiva la funzione e inquadra il codice QR mostrato sullo schermo con la fotocamera del tuo iPhone.
3. Il browser aprirà la versione web leggera di RT. Puoi salvarla sulla schermata Home come web app per un accesso immediato a tutto schermo.

## API di sola lettura e agenti

RT espone una serie di API locali in sola lettura protette da token, ideali per integrare assistenti o agenti intelligenti (come Claude Desktop, Open WebUI o script di studio):
- **API di sola lettura**: permettono di interrogare l'elenco delle lezioni, recuperare il testo rielaborato di una specifica unità o cercare concetti tra le materie senza rischiare di alterare i dati originali.
- **Prompt per gli agenti**: nella schermata delle impostazioni API trovi modelli di prompt pronti da copiare nel tuo assistente preferito per istruirlo a consultare la tua base di conoscenza su RT come tutor personale.
