# File e formati di RT

RT utilizza formati aperti e archivi trasparenti per consentirti il pieno controllo e la portabilità dei tuoi dati.

## I formati di file

- **`.rt` (Archivio di singola lezione)**: è un archivio compresso contenente l'intera storia di una lezione: metadati, trascrizione, testo rielaborato per unità, riferimenti alle fonti, immagini e verifiche. È il formato ideale per condividere una lezione con un collega o fare un backup puntuale.
- **`.rtdb` (Archivio del database)**: è un archivio di backup dell'intero database SQLite di RT. Contiene la struttura di tutte le lezioni, impostazioni, materie e cronologia dei ripassi.
- **`.rtcal` (Calendario di studio)**: contiene la programmazione temporale, le sessioni di studio e le scadenze del calendario.

## Esporta e importa

Puoi accedere alle funzioni di trasferimento dati dall'interfaccia:
- **Esporta lezione**: dalla pagina della lezione o dal menu opzioni, seleziona **Esporta in .rt** per creare un singolo pacchetto condivisibile.
- **Importa lezione**: trascina un file `.rt` nella finestra dell'app o usa il pulsante **Importa** nella schermata principale per aggiungere la lezione alla tua raccolta.
- **Collezione completa**: dalle Impostazioni puoi esportare o ripristinare l'intera base di dati di RT in tutta sicurezza.
