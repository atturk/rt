# Chiavi API e costi

RT non richiede alcun abbonamento ricorrente né costi di licenza. Per le funzioni di trascrizione audio e intelligenza artificiale, RT si connette direttamente ai fornitori di modelli linguistici tramite le tue chiavi API personali.

## Come funzionano le chiavi API

Per abilitare l'elaborazione delle lezioni:
1. Vai in **Impostazioni → Modelli**.
2. Inserisci la chiave API del fornitore scelto (es. OpenAI, Anthropic Claude, Google Gemini, Groq o un fornitore compatibile).
3. Puoi anche usare modelli locali tramite Ollama, a costo zero e senza inviare dati all'esterno.

Le chiavi vengono salvate esclusivamente sul tuo computer locale nel file di configurazione protetto e non vengono mai condivise con sviluppatori terzi.

## Quanto costa elaborare una lezione

I costi dipendono dalle tariffe del fornitore e dalla lunghezza della lezione:
- Paghi solo i token effettivamente consumati direttamente al fornitore dell'API.
- Una lezione universitaria tipica di circa 90 minuti richiede indicativamente tra 0,05 € e 0,30 € complessivi a seconda del modello selezionato per trascrizione ed elaborazione.
- Nella schermata **Impostazioni → Modelli** e nel riquadro di benvenuto viene mostrata una stima orientativa dei costi per lezione in base al modello configurato.
