# Calendario e pianificazione

La vista **Calendario** offre una panoramica temporale del tuo percorso di studi, integrando le lezioni svolte con le scadenze e le sessioni di ripasso.

## Organizzazione settimanale e mensile

- Puoi visualizzare le lezioni distribuite per giorno e per materia.
- Cliccando su una data puoi pianificare blocchi di studio o registrare future lezioni in programma.
- Le scadenze d'esame e le sessioni di ripasso programmato vengono evidenziate per aiutarti a gestire il carico di lavoro prima degli appelli.

## Esportazione calendario (.rtcal)

I dati del calendario possono essere esportati e importati tramite file in formato `.rtcal`, consentendo di sincronizzare o archiviare i piani di studio in modo leggero e indipendente.
