# RT — Assistente allo studio universitario e scolastico

RT è un'applicazione open source pensata per accompagnare gli studenti durante tutto il percorso di apprendimento:
- Registra le lezioni dal vivo o carica file audio e video già registrati.
- Trascrive e rielabora il parlato suddividendolo in unità di studio chiare e coerenti.
- Confronta il testo con le slide e i materiali del docente per rilevare incongruenze e dubbi.
- Offre un ambiente di studio integrato con evidenziazioni, lettura veloce, modalità zen e flashcard.
- Funziona al 100% in locale sul tuo computer, garantendo la totale riservatezza dei tuoi dati.
