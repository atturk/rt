# Immagini del sito di RT

Le immagini della landing page (`docs/sito/index.html`):

- `icona.svg`: icona e favicon (copia di `frontend/public/favicon.svg`).
- `lezione-chiaro.webp`, `lezione-scuro.webp`: schermata della lezione di esempio, tema chiaro e
  scuro, 2560×1600 (finestra 1280×800 a densità 2). Per sostituirle tieni lo stesso nome e formato.
